# Traya Yukti Core (TYC) — Careers

Internship Recruitment Programme careers page. Static site, no build step — open `index.html` or serve the folder with any static host.

## Deployment

`.github/workflows/deploy.yml` publishes the site to GitHub Pages automatically on every push to `main`. Pages is enabled by the workflow itself (`enablement: true`); the live URL appears under **Settings → Pages** after the first run.
